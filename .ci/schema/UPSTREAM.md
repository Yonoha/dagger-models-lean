# Vendored reporting schema

`formalization-v0.4.schema.json` is an unchanged copy of
`schema/v0.4.schema.json` from
[mathlib-initiative/formalization.yaml](https://github.com/mathlib-initiative/formalization.yaml/tree/99c678e569c7c4c0772db297c5ddd5e4c9b6322e),

The upstream project distributes it under Apache-2.0, the license reproduced
in this repository's `LICENSE`. Keeping this schema locally fixes the validation
rules and avoids changing a historical check when upstream updates `main`.
