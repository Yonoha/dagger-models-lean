# Part I companion publication: v0.2.0-rc1

This release candidate contains the original A/B/C/D formalization snapshot and an English catalogue prepared as a companion to Part I. The author authorized publication on October 19, 2026.

## Scope

The original mathematical source snapshot is `dfee9b568d8f67980b164fa830d189d106951a57`; its accepted local documentation snapshot is `d045ef954e1772463b92b5317fb2377f24d369ac`. The publication adds documentation, saved validation receipts, publicly fetchable hash-pinned verification inputs, and the current hosted-workflow configuration. It does not alter the 2771 Lean library sources in `SOURCE_MANIFEST.json`.

The saved local ARM64 Linux acceptance covers the full 2771-module build, 40022 owned declarations, 71 advertised results, eight main roots, nine B/C/D cases, five A cases, and four rejected axiom-audit controls. Initial and separately restored owner-audit logs are byte-identical. The run continued from a partial cache; it was not a cold rebuild or a fresh execution of the current integrated controller. The receipts are preserved unchanged in `verification/local-linux-20261018/`.

The new hosted workflow is enabled for the publication commit. Its actual status is visible in GitHub Actions; this document does not claim that it has passed. Independent human review of manuscript correspondence has not been recorded. The Challenge files for the main results import project definitions and are not independent Mathlib-only specifications.

## English catalogue

The release PDF contains 40 grouped results, with 91 named Lean declarations in 58 source files. Its notation follows Part I. The opening page states that the prose, English translation, and result summaries were generated by AI agents. The editable LaTeX is in `docs/formalization-companion/`.
