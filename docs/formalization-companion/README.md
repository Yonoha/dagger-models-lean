# English formalization catalogue

This catalogue is a companion to *Models for dagger (infinity,1)-categories I: Dagger simplicial sets and unitary cores*. Its prose, English translation, and summaries were generated by AI agents from the manuscript and Lean source. The opening page of the PDF states this explicitly.

The 40 entries retain the notation of Part I and identify 91 Lean declarations in 58 source files. They distinguish project-specific formalization work from reused Mathlib and TopCatModelCategory foundations. A result entry is not a claim of independent mathematical novelty.

## Build the document

Compile `main.tex` with LuaLaTeX (TeX Live 2025 was used):

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error main.tex
```

All supporting files are included in this directory; no local manuscript paths are required. The PDF is distributed as a release asset. `part1-notation.tex` copies the relevant notation definitions from Part I.

The last section states the precise scope of saved local verification and the remaining independent-review and hosted-CI boundaries.
