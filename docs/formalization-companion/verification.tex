\subsection{Statement correspondence and Comparator}
The main results have separate Challenge and Proof entry points.
Comparator tests help detect deviations from the fixed Lean statements.
They do not by themselves establish that those statements express the intended mathematics of the paper.
The Challenge files currently import project definitions rather than specifying the problems independently from Mathlib alone.
For example, the Challenge for A has 48 physical lines, but its transitive import closure contains 366 modules and 679,416 lines.
Consequently, inspecting the short Challenge file alone does not inspect all mathematical definitions on which it depends.
Manuscript correspondence has undergone AI-agent review; independent human review of that correspondence has not yet been completed.

Parts of the general Smith machinery use restored closed proof terms.
This catalogue records the concrete applications whose types and hypotheses are available for inspection.
Likewise, the weak-equivalence criterion for a given localization is stated with that localization as an assumption; it is not a Bousfield-localization existence theorem.
